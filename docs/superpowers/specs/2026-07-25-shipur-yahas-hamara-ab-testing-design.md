# Design: Blog article — שיפור יחס המרה (continuous A/B)

**Date:** 2026-07-25  
**Status:** Angle approved 2026-07-25 — proprietary continuous A/B system; client-facing “behind the scenes”; Lev bio (18y ads / 13y independent)  
**Skills:** `seo-write-content` (inhouseseo), `seo-content-brief`, local `ab-testing` / `cro` / `copywriting`

## Goal

Organic SEO article targeting primary keyword **שיפור יחס המרה**. Capture high-intent (low-volume, high CPC) searchers in Israel. Differentiate Profit Media via continuous A/B on page elements + ads/audiences in one system (same philosophy as Donhin experiments). CTA: free campaign diagnosis.

## URL (proposed)

`/blog/shipur-yahas-hamara`  
Latin slug for ops; keyword in H1/title/description.

## Content type

**How-to + practitioner explainer** (not a thin definition page).  
SERP competitors are generic CRO guides → we win with: what to test in order, conversion as the metric, continuous loop (headline → sticky → popup → ads/audiences), honest limits.

## Unique angle

- Infinite / continuous A/B: crown a winner → introduce a new challenger based on what won  
- Elements: headlines, sticky CTA copy, popups, then creatives + audiences  
- Metric: conversions (qualified inquiries), not clicks vanity  
- Personal measurement system (like Donhin ab-stats) — describe outcome, not internal URLs/secrets  
- Ties to existing posts: landing vs homepage, paid campaigns guide  

## Outline (Hebrew article)

1. Short answer block — what שיפור יחס המרה means in paid campaigns  
2. Why media budget without page tests wastes money  
3. What to measure (conversion / qualified lead — not only CPL vanity)  
4. Continuous A/B loop (champion → challenger)  
5. Page elements priority: headline → CTA/sticky → popup/form  
6. Ads + audiences in the same learning loop  
7. Soft field example (no fake %; optional real number if Lev provides)  
8. Who should NOT chase endless tests yet  
9. FAQ (5–6)  
10. CTA: אבחון קמפיין  

## Constraints (voice / honesty)

- Hebrew, practitioner tone (I/we), Profit Media brand  
- No sales guarantees; no invented case stats  
- Avoid overclaiming “רוב” without evidence  
- Prefer deals / פניות מתאימות language from product marketing  

## Assets

- Register in `blog.ts`, page `.astro`, sitemap, deploy  

## Success criteria

- Live URL indexed request in GSC  
- Title/H1/meta contain primary KW naturally  
- Internal links to/from the two existing posts  
- Distinct from generic CRO SERP: continuous system story clear in first scroll
